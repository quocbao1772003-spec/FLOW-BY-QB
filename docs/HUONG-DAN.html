Local-only Google Flow Pro/Ultra Chrome MV3 React + FastAPI

Tác giả: Quốc Bảo — Handora Team

1. Giới thiệu

Flowboard là một workspace canvas vô hạn chạy ngay trên máy bạn, dùng để dựng các quy trình tạo ảnh/video bằng AI dưới dạng các node nối với nhau. Mỗi lệnh tạo ảnh/video được gửi qua một extension Chrome tới Google Flow (Veo 3.1 & GemPix 2), dùng chính tài khoản Flow của bạn.

Mỗi người dùng một bản riêng trên máy mình và đăng nhập tài khoản Flow riêng — board và ảnh của ai nằm trên máy người đó.

3. Cài đặt

📦 Link mã nguồn (công khai): github.com/quocbao1772003-spec/FLOW-BY-QB
Repo công khai nên ai cũng clone được, không cần token hay đăng nhập GitHub.
1Clone mã nguồn

Mở terminal Ubuntu (WSL) và chạy (không cần đăng nhập/token):

git clone https://github.com/quocbao1772003-spec/FLOW-BY-QB.git
cd FLOW-BY-QB
make install

Lệnh make install tự tạo môi trường Python cho agent và cài thư viện cho frontend (mất vài phút). Repo là công khai nên clone không cần đăng nhập hay token gì cả.

3.1 Load Chrome extension

2Nạp extension vào Chrome
  1. Mở Chrome, vào chrome://extensions
  2. Bật Developer mode (góc trên phải)
  3. Bấm Load unpacked → chọn thư mục extension/ trong repo
  4. Mở tab labs.google/fx/tools/flow và đăng nhập tài khoản Flow của bạn
  5. Icon extension sẽ chuyển màu khi bắt được phiên Flow (~5 giây)

3.2 Chạy app

3Khởi động agent & frontend

Mở 2 terminal riêng:

# Terminal 1 — backend
make agent      # chạy FastAPI ở cổng 8101

# Terminal 2 — frontend
make frontend   # chạy Vite ở cổng 5173

Sau đó mở trình duyệt vào http://localhost:5173.

💡 Kiểm tra agent đã chạy đúng: dòng trạng thái phía trên canvas hiển thị ● agent ● extension màu xanh.

4. Sử dụng

4.1 Sidebar & 3 trang chính

Thanh bên trái có thể thu gọn (bấm nút panel cạnh logo). Ba trang:

  • Flows — thư viện tất cả flow (board). Bấm card để mở, nút + New flow tạo flow mới, hover card hiện nút xóa.
  • Image Gen — tạo ảnh lẻ không cần canvas (xem mục 4.7).
  • Library — xem lại toàn bộ ảnh/video đã tạo (xem mục 4.8).

Bấm logo Flowboard để quay về canvas.

4.2 Node trên canvas

Thêm node: bấm nút + ở toolbar trái → chọn loại (Text, Image, Video, Storyboard, Visual asset, Assistant…), hoặc chuột phải lên canvas để mở menu nhanh.

Loại nodeCông dụng
ImageTạo ảnh. Nhập prompt trực tiếp trên card, chọn số biến thể (x1–x4), model, tỷ lệ. Bấm ▶ để tạo ngay. Khung node tự khớp tỷ lệ ảnh.
VideoTạo video từ ảnh (image-to-video) qua Veo.
StoryboardNhiều cảnh (shot) trong một node.
Character / Visual assetẢnh tham chiếu — upload hoặc generate, dùng làm nguồn cho node khác.
AssistantChạy mô hình ngôn ngữ (Claude/Gemini) tự do để soạn nội dung.
Text / NoteGhi chú, prompt mồi.

Nối node: kéo từ ô vuông cạnh node này thả vào ô vuông node kia → tạo đường nối (reference).

Cắt kết nối: bấm vào một đường nối → hiện nút ✂ ở giữa → bấm để ngắt.

Đổi ảnh: nút ⇄ Replace ở góc dưới ảnh để upload ảnh khác thay tại chỗ.

4.3 Tag node & reference trong prompt

Khi nhập prompt trên node Image hoặc Assistant, gõ @ để mở danh sách → chọn node muốn tham chiếu. Hệ thống sẽ tự nối node đó làm nguồn và chèn thẻ @Tên #id được tô màu. Ảnh/nội dung của node được tag sẽ được đưa vào làm cơ sở khi generate.

4.4 Chạy pipeline (Run from here)

Chọn một node → trên thanh công cụ nổi của node có nút ▶▶ với 2 lựa chọn:

  • This node only — chỉ chạy đúng node đó.
  • Run from here — chạy node đó rồi lan xuống toàn bộ node phía sau theo thứ tự. Node sau sẽ đợi node trước tạo xong, lấy ảnh/text vừa tạo làm đầu vào, rồi mới chạy. Nếu một node lỗi, cả chuỗi dừng lại.
Khi pipeline đang chạy, các đường nối tới node đang xử lý sẽ chạy sáng màu xanh để báo hiệu.

4.5 Group node

Quét chọn nhiều node (kéo khung chọn, hoặc Shift+click) → toolbar nổi có nút Group để gộp thành một khung. Khi chọn khung group, toolbar riêng cho phép:

  • Đổi màu nền khung
  • Ungroup — tách nhóm (node giữ nguyên)
  • Arrange — sắp xếp node bên trong: Dọc / Ngang / Lưới
  • Lock — khóa, không kéo được node trong nhóm
  • Duplicate — nhân bản cả nhóm
  • Download — tải toàn bộ ảnh trong nhóm, mỗi ảnh một file riêng
  • Delete — xóa nhóm và toàn bộ node bên trong

Kéo khung group = di chuyển tất cả node bên trong cùng lúc.

4.6 Image Editor

Mở từ nút ✎ trên toolbar node ảnh, hoặc nút AI edit / Crop & Flip trong cửa sổ xem kết quả.

  • AI edit — nhập mô tả thay đổi → AI sửa ảnh.
  • Crop & Flip — cắt theo tỷ lệ định sẵn (1:1, 9:16, 16:9…), lật ngang/dọc, có lưới 1/3 và 8 điểm kéo.

Trong cửa sổ xem kết quả: lăn chuột để phóng to/thu nhỏ ảnh, kéo để di chuyển, double-click để reset. Bốn nút: AI edit · Crop & Flip · Download · Re-generate (tạo lại).

4.7 Trang Image Gen (tạo ảnh lẻ)

Tạo ảnh nhanh không cần dựng canvas:

  1. Mục REFERENCES: bấm + Add để upload ảnh tham chiếu (tối đa 4).
  2. Nhập PROMPT, gõ @ để tag ảnh tham chiếu vừa upload.
  3. Chọn số biến thể và tỷ lệ → bấm Generate (hoặc Ctrl+Enter).
  4. Kết quả hiện ở khung phải theo thời gian thực, bấm ảnh để mở xem chi tiết.

4.8 Trang Library

Hiển thị toàn bộ ảnh & video đã tạo từ mọi flow và từ Image Gen. Có bộ lọc All / Images / Videos, hover vào ảnh để hiện nút tải về, nút refresh để cập nhật.

6. Cập nhật app khi có bản mới

Khi quản trị repo đẩy bản cập nhật lên GitHub, chỉ cần một lệnh:

cd FLOW-BY-QB
make upgrade

Script sẽ tự: tải code mới (git pull) → cài lại thư viện nếu có thay đổi → nhắc reload extension nếu cần. Dữ liệu của bạn (board, ảnh) không bị mất vì được lưu riêng và không nằm trong git.

Sau khi cập nhật xong, khởi động lại make agent và make frontend, rồi tải lại trình duyệt bằng Ctrl+Shift+R.

Nếu make upgrade báo "uncommitted local changes" → bạn đã lỡ sửa code. Chạy git stash để cất tạm rồi make upgrade lại.

7. Xử lý lỗi thường gặp

Nút ▶ Generate không có phản hồi

Kiểm tra: (1) đã load extension chưa, (2) tab labs.google/fx/tools/flow còn mở và đã đăng nhập chưa, (3) dòng trạng thái có ● extension xanh không. Mở lại tab Flow để extension bắt lại phiên.

"Open Flow once so the extension can detect your plan"

Extension chưa nhận diện được gói tài khoản. Mở/refresh tab Flow một lần, đợi vài giây rồi thử lại.

Ảnh tải lên chậm

Ảnh được tự động nén về tối đa 2048px trước khi gửi. Nếu vẫn chậm là do tốc độ mạng upload tới Google Flow — nằm ngoài tầm kiểm soát của app.

Agent không chạy / cổng 8101 bận

Đảm bảo không có tiến trình cũ đang chiếm cổng. Dừng (Ctrl+C) rồi chạy lại make agent.

Giao diện không cập nhật sau khi pull

Hard-refresh trình duyệt: Ctrl+Shift+R. Nếu sửa extension thì phải vào chrome://extensions bấm ↻ Reload.

🔒 Bảo mật: không chia sẻ tài khoản Google Flow của bạn cho người khác. Mỗi người dùng tài khoản Flow riêng.
